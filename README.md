# CrownedPvP resource pack

Server resource pack for CrownedPvP Season 1: the team menu (dialogs and chest fallback), flags, alliance markers and the pixel-art legendary weapons with their tooltips.

The server downloads the pack straight from this repository. Every release gets its own file name in `packs/`, so an old link never serves new content and the SHA1 in `server.properties` always matches.
